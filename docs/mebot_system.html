📡 Detalle: Fase 6 — Escalado Masivo (Fleet & OTA)

Esta fase permite orquestar decenas de ESP32 de forma simultánea. Se pasa de una arquitectura 1-a-1 a una topología en estrella donde el Bridge coordina la flota completa por WiFi y la interfaz HTML.

1. Heartbeats & Registro Automático

  • 📡ESP32 (C/C++): Cada robot envía un ping a POST /api/register cada 60s con su MAC, IP y versión de FW.
  • 🧠Bridge (Python): main.py registra cada dispositivo en una base de datos local (ej. device_registry.json).

2. Panel de Flota (fleet.html)

  • 🖥️UI Maestra: Tabla centralizada con estado en vivo (Online/Offline) de cada ESP32.
  • 🎛️Acciones Masivas: Checkboxes para seleccionar dispositivos y enviar comandos en lote (Reset, Mute, Actualizar).

3. Flujo OTA Inalámbrico

  • 📥Subida HTML: El Admin sube firmware.bin en la web, el Bridge lo aloja en /firmware/.
  • ⚡Broadcast WS: El Bridge envía comando JSON masivo: {"cmd":"ota", "url":"http://10.x.x.x:16000/firmware.bin"}.
  • 🛠️Flasheo ESP32: El robot descarga el binario con esp_http_client, lo escribe vía esp_ota_ops y reinicia. Rollback automático ante fallos.
